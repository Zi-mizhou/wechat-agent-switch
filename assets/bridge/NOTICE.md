This distribution adds optional native agent adapters, isolated slash-command routing, local image response handling and a Windows watchdog. It is a community integration, not an official integration endorsed by WeChat, OpenAI, DeepSeek or WorkBuddy.

WorkBuddy's proprietary application files and account credentials are not included. Native adapters load the user's own installed applications and may require adaptation after application updates.
